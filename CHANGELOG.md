# KNIGHT SENSI

KNIGHT SENSI is a professional sensitivity calibration and analysis laboratory for Free Fire-style mobile aim tuning. The platform is designed to preserve a realistic, explainable calibration workflow instead of offering fake or opaque automation.

## Features

- Device discovery and fuzzy search with Realme C30 validation
- Multi-attribute calibration model using device, DPI, refresh, playstyle, and weapon weighting
- Explainable sensitivity outputs for General, Red Dot, 2X, 4X, Sniper/AWM, and Free Look
- Confidence, robustness, and double-check analysis
- Test lab and feedback tracking
- Local history and export support for JSON, TXT, and PNG card output
- Offline-first local storage workflow
- Mobile-first, accessible dashboard interface
